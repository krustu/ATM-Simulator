# ATM Simulator

A simple and well-structured console-based ATM simulator written in C#. This project demonstrates the core concepts of Object-Oriented Programming (OOP) and basic architecture.

##  Key Features
* Balance Management: Easily deposit, withdraw, and track funds.
* Persistent Session: Account balances and data are preserved throughout the execution session instead of resetting after every single operation.
* Flexible Navigation: Features multiple intuitive menus with the ability to go back to the previous screen or return to the main menu easily.
* Input Validation: Robust error-handling to validate user inputs (preventing crashes from invalid characters, empty values, or incorrect amounts).

##  Project Architecture & Advantages
* Clean Code: Cleanly separated into dedicated classes and methods following best practices.
* Folder Structure: Organized neatly into folders, making the project highly maintainable and easy to scale.
* Reliability: Computational logic is strictly separated from the console presentation layer.
